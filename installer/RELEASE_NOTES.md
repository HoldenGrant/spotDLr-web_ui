## Install spotDLr on Windows

1. Download **spotDLr-Setup.exe** below.
2. Double-click it. Windows may say **"Windows protected your PC"** because the installer isn't signed: click **More info → Run anyway**. You only see this once.
3. Click through the installer (no admin password needed) and leave **Open spotDLr** ticked.

From then on, open **spotDLr** from the Start menu (or the desktop icon). It opens in its own window.

- **Search** for any song, artist or album and click the download button. Songs you already have show a green check.
- **Paste a Spotify or YouTube Music link** into the search box to download a song, album or playlist (Spotify playlists: first 100 songs).
- Your music is saved in **Music → spotDLr**. Uninstalling spotDLr never deletes it.
- Closing the window closes spotDLr.

No Spotify account is needed.
